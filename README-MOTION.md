# Camada visual com animações

Esta versão adiciona uma camada visual inspirada em interfaces modernas de estúdios digitais:

- fundos com gradientes radiais sutis;
- entrada suave dos blocos;
- animações ao aparecer durante a rolagem;
- efeito de brilho nos botões principais;
- hover suave em cartões;
- suporte a `prefers-reduced-motion`;
- compatibilidade com a estrutura existente, sem alterar consultas do Supabase.

A URL de referência não pôde ser carregada durante a preparação, portanto esta é uma interpretação visual inspirada, não uma cópia pixel a pixel.
